06 · fractals

A tiny formula → infinite complexity

Recursion: a function that calls itself. Mandelbrot, Sierpinski, branching trees. Zoom in: there is always more.

01 function branch(len) {
02   line(0, 0, 0, -len);
03   translate(0, -len);
04   if (len > 8) {
05     push(); rotate(angle); branch(len * 0.67); pop();
06     push(); rotate(-angle); branch(len * 0.67); pop();
07   }
08 }

Scroll to grow the tree. In generative art, infinity fits in a few lines of code.

automata

08 · cellular automata

The artist writes rules.
The work writes itself.

Conway's Game of Life: a grid of cells, alive or dead, and three simple rules. From that minimalism, behaviors emerge that mimic populations, fires, entire ecosystems.

01 if (alive && neighbors < 2) die;        // loneliness
02 if (alive && neighbors > 3) die;        // overpopulation
03 if (alive && (neighbors == 2 || neighbors == 3)) live;
04 if (dead && neighbors == 3) become alive; // birth

Nobody programs the patterns you see, they emerge. Click or drag to paint life, scroll to reseed.
